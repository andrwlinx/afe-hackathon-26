# RampPath Demo Script

Target length: 3 minutes.

## 0:00 - The blocker

"A new intern rarely knows which system contains the answer. A simple access
question can require checking package ownership, a pipeline, an account,
Bindle, and an approver."

## 0:20 - Find the right person

Run `Who knows about AtlasRegionContext?`

Show the ranked people, normalized scores, and the keyword, relationship, and
recency components under "Why this person."

## 0:55 - Ownership

Run `Who owns AtlasRegionContext?`

Point out the owning team, named contact, visible graph path, and package
metadata evidence.

## 1:15 - Access gap

Run `Can I edit supported locations in prod?`

Point out that RampPath does not claim a denial. It proves the resource requires
`AtlasProdOperator`, shows that the current intern has no observed assumption
edge, and identifies the verified approver.

## 1:50 - Next action

Run `What access should I request to edit supported locations in prod?`

Copy the drafted request. Emphasize that its role and recipient came from graph
records rather than generated prose.

## 2:20 - Deployment context

Run `Where does AtlasRegionContext deploy?`

Show the package-to-pipeline-to-stage-to-account paths for Alpha and Prod.

## 2:45 - Pay it forward

"Every solved blocker becomes a reusable path with provenance and freshness.
The next intern starts from an answer and an action, not six disconnected
systems."

End on the path view with the source evidence visible.
